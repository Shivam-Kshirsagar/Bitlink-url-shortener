Bitlink - URL Shortener

A fast, modern, and minimal URL shortener built with Next.js 14.

**Live Demo:** https://Shivam-Kshirsagar.github.io/Bitlink-url-shortener/

---

### ✨ Features
- Instant URL shortening
- Clean and minimal UI with Tailwind CSS
- Built on Next.js 14 App Router
- 【entity-MongoDB¦canonical_name=MongoDB】 integration
- Fully responsive

### 🛠️ Tech Stack
- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Database:** 【entity-MongoDB¦canonical_name=MongoDB】
- **Deployment:** Vercel
